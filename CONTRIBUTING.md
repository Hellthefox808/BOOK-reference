# Contributing to BookVerse

Thank you for your interest in contributing to **BookVerse – Online Book Reading Platform**.

## 🚀 Getting Started

1. **Fork & Clone** the repository:
   ```bash
   git clone https://github.com/your-username/bookverse.git
   cd bookverse
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```

4. **Run Verification & Build**:
   ```bash
   npx tsc --noEmit
   npm run build
   ```

## 🎨 Coding & Design System Rules
- Follow the Coffee-Tone Visual System (`bg-[#f6efe7]`, `dark:bg-[#100d0c]`, coffee color tokens).
- Maintain motion caps under `250ms`.
- Respect `prefers-reduced-motion` and `prefers-reduced-transparency`.
