# Changelog

All notable changes to **BookVerse** will be documented in this file.

## [1.0.0-MVP] - 2026-07-31

### Added
- **120 Canonical Titles Reference Catalog**: 120 books across 12 genres in `seed-books.json` and `PRD.md`.
- **Coffee-Tone Design System**: Latte, mocha, and espresso themes (`#f6efe7` light cream, `#100d0c` dark espresso).
- **Web Reader Engine**: EPUB & PDF reading modal supporting font size adjustments, serif/sans/mono typography, light/dark/sepia/midnight themes, table of contents jumper, and reading progress saving.
- **Enterprise Data Fetching Engine v150**: Centralized `ApiClient` with request cancellation (`AbortSignal`), TanStack Query query/mutation caching, request deduplication, and normalized `ApiError` structures.
- **AI SaaS Orchestration Engine v1000**: AI Reading Assistant drawer providing chapter summaries, contextual Q&A, and vocabulary explanations.
- **Interactive Auth Portal (`/login`)**: Animated background canvas, password strength meter, OTP verification modal, forgot password reset flow, and Google OAuth 2.0.
- **GitHub Production Ecosystem**: GitHub Actions CI/CD pipeline, issue templates, PR template, `CONTRIBUTING.md`, `SECURITY.md`, `LICENSE`.
