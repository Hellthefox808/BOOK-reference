# UX Principles

## 1. Distraction-Free Immersion
- In reading mode, chrome and controls automatically auto-hide after 3 seconds of inactivity or scroll.
- Fullscreen reader mode provides zero visual clutter outside content.

## 2. Zero-Loss State Retention
- User reading position, selected font, theme settings, and line height are persisted automatically via local storage and synced to the cloud via background debounced requests.

## 3. Universal Accessibility (WCAG 2.1 AA)
- Full keyboard accessibility for page flipping, bookmarking, and navigation.
- High contrast color themes with screen-reader accessible ARIA roles for reader controls.
